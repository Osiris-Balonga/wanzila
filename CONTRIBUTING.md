# Contribuer

Créer une branche depuis `dev` et ouvrir une pull request vers `dev`. Les changements validés passent ensuite de `dev` vers `main`. Ne pas pousser directement sur `dev` ou `main`.

Avant une PR, lancer `npm ci` et `npm run build`, puis vérifier manuellement la recherche, les fiches et les itinéraires sur ordinateur et mobile. La CI se limite au build ; ce projet n’a pas de suite de tests automatisés.
