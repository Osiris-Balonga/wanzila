# Security policy

Do not report security issues through public GitHub Issues. Contact the repository owner privately through the contact information on their GitHub profile.

Never commit credentials or production environment files. JSON Server must stay on a loopback or private interface: its native API permits unauthenticated writes. The public Next.js relay accepts only GET and HEAD.

This demonstration must not store precise historical user location. Location use is limited to the active route and must stop when the route ends.
